Core Course:

Database Management Systems (DBMS)

Key DBMS Concepts Demonstrated:

1. Relational Modeling & Normalization: Decomposed unnormalized entities into 8 atomic tables meeting 3NF and BCNF guidelines, avoiding redundant department and user metadata across tickets.
2. Referential Integrity & Constraints: Enforces Primary Keys, Foreign Keys with `ON DELETE CASCADE` and `ON UPDATE CASCADE`, `UNIQUE` constraints on ticket numbers, and `CHECK (rating >= 1 AND rating <= 5)`.
3. ACID Transactions: Multi-table operations (e.g. ticket submission, dispatching technicians, recording audit trail) run within simulated `BEGIN TRANSACTION ... COMMIT` blocks to guarantee Atomicity and Consistency.
4. Automated Database Triggers: Triggers simulate automatic stage progression: updating status to 'Assigned' upon technician dispatch, recording chronological history in `complaint_updates`, and auto-closing tickets upon student feedback.
5. Role-Based Access Control (RBAC): Three explicit user tiers (Administrator, Department Staff, Student/Reporter) with partitioned permissions and access controls.
6. Progressive Web App (PWA) Offline Caching: Integrated Service Worker (`sw.js`) and Web App Manifest enable instant offline loading and mobile homescreen installation.
